01 / 直接编辑

在浏览器里开始

打开编辑器，导入 HTML 或工程文件，也可以从模板新建。

  • 文字、样式、布局与图层
  • 图表数据、动效预览与导出
  • 无需启动本地连接器
打开编辑器
建议使用 Chrome 或 Edge。此入口不会启用 MCP。
02 / AI 编辑

让 AI 助手来操作

把启动提示词发给电脑上能执行本机命令的 Agent，由它启动本包的 AI 连接器。

  • 支持原有 31 个 MCP 工具
  • 启动后在编辑器内配置并授权
  • 本地运行环境已包含在安装包中
浏览器不能直接启动本机程序，复制后需要交给 Agent 执行。
从直接编辑切换到 AI 编辑前，请先保存工程。
两个入口的浏览器草稿不自动同步；启动 AI 连接后，在新页面重新导入保存的工程即可。
查看启动提示词
没有能操作本机的 Agent？使用备用入口

回到本安装包文件夹，双击 __SCRIPT_NAME__。它会打开 AI 编辑页面；保持启动窗口运行。接着点击编辑器右上角「连接 AI」，完成配置与授权。

HTML 文件本身不运行本地程序。若电脑策略也限制运行本包的连接器或脚本，请使用直接编辑模式，或联系设备管理员；此入口不会绕过系统限制。
