# html全能编辑器

独立网页版 HTML 可视化编辑器，当前版本 **v0.5.0**。可在本地编辑 HTML、演示文稿和受支持的数据图表，也可通过 MCP 让本机 AI Agent 操作已授权工程。

## 下载与使用

[下载最新轻量包（约 3.21 MB）](releases/html全能编辑器-v0.5.0-轻量版.zip?raw=true)

1. 完整解压 ZIP，双击「启动 html全能编辑器.html」。
2. 点击「打开编辑器」，导入 HTML / `.htmlstudio` 工程，或从模板新建。
3. 编辑后预览，再保存工程或导出 HTML。

推荐电脑端 Chrome 或 Edge。手动编辑无需 Node.js、无需服务器；也可直接打开根目录的 `HTML Studio.html`。浏览器草稿仅保存在当前浏览器及地址下，请另存工程用于备份或切换入口。

## 主要能力

- 文字、字体、颜色、尺寸、透明度、描边、阴影、基础形状及 SVG 编辑；图片和视频插入。
- 图层选择与定位、多选、对齐分布、复制删除、组合与解绑、Flex / Grid 布局。
- 容器「适应内容尺寸」：收紧宽高，优先保留内部元素尺寸和间距；必须改变布局规则时先确认，支持批量操作与撤回。
- 多页 HTML 演示文稿的逐页编辑、真实缩略图、拖动排序、页面新增/复制/删除。
- 普通表格与基础公式、图表数据批量粘贴；受支持图表的数据修改及行列增删。
- SVG 柱状/堆叠/瀑布/气泡图、HTML/CSS 柱状图和占比条、Chart.js 等结构的样式保留适配。识别不可靠时提示限制，并由用户决定是否转换。
- 34 款模板、封面预览、常用字体内置，其余模板字体按需下载与缓存。
- CSS 动效与轻量 JavaScript 交互预览、工程保存、HTML 导出、撤回重做。
- 31 项 MCP 工具，覆盖图表、表格、文字、样式、几何、布局和图层操作。

## 连接 AI

轻量入口中点击「复制 AI 启动提示词」，发给具备本机执行能力的 Agent。启动助手优先复用 Node.js 24+；缺少时才从 Node.js 官网下载并校验运行环境。运行环境不随本包分发。

在新打开的编辑器中点击「连接 AI」，完成客户端配置并授权当前工程。Codex 有快捷配置入口；其他客户端的自定义 MCP 支持情况取决于其版本。可先发送：

> 查看当前已授权工程有哪些图表，以及它们的数据，先不要修改。

连接器仅监听本机。Agent 使用云端模型时，读取的内容仍可能发送给模型服务；本地连接不代表全程离线。未授权工程不会开放给 MCP。

## 开发

使用 Node.js 24+。运行前端不需要安装依赖：

```sh
npm start
# 浏览器访问 http://127.0.0.1:4387
```

前端源码位于 `dist/`。修改后构建独立 HTML：

```sh
npm run check
npm run build:standalone
```

重建连接器：

```sh
npm ci --ignore-scripts --prefix connector
npm run build:connector
```

`connector/connector.cjs` 已预构建。`launcher/lite/` 是轻量入口及按需启动脚本。[内部接口说明](docs/内部操作接口-v1.html) 与 `connector/command-schema.json` 可用于查看接口定义。

模板、封面及常用字体已包含在生成的 JS 模块中，普通构建无需下载完整字体缓存。重新生成模板素材、运行历史测试和重新打包的前置条件见 [开发与测试说明](docs/开发与测试.md)。

## 验证与边界

本次公开的 ZIP 与本地已验证包完全一致，包含 15 个文件；[SHA-256 校验值](releases/SHA256SUMS.txt) 可用于核验下载。

已有验证记录：轻量包 16 组、容器适应内容 17 组、相关 MCP 21 条记录（含性能记录）、文字退出 10 组、双击编辑 9 组通过。详见 [轻量版测试报告](docs/轻量版-回归报告-v0.5.0.html)。这些是已有测试范围，不代表任意 HTML 都可无损编辑。Windows 尚未实机验证。

不支持任意网页应用源码还原、任意 Canvas 像素反推数据、钢笔节点编辑或多人协作。复杂脚本、外部资源、响应式约束与第三方图表可能受限；导入检查会提示已识别的问题，仍需预览确认。整页和图表内部不按普通容器收紧；阴影不计入适应尺寸。

源码仓库不包含个人工程、浏览器草稿、配对凭据、测试截图或旧版 Node.js 运行环境。
