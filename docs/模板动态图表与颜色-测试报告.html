使用方式

  1. 从新版编辑器的模板库新建文件，选中图表，点击「编辑图表数据」，或双击数据图形／数值。
  2. 修改数值，查看实时预览；展开「单个数据元素颜色」，逐项输入 HEX 或使用取色器，随时恢复原色。
  3. 进入预览或导出后打开页面：图表从零增长到最新数值；再次进入该页会重播。开启系统减少动态效果时直接显示终态。

处理规则与边界

  • 13 个示意图按原比例初始化为相对数值，并在数据面板明确说明。数字与原几何不一致的图，以数字校正比例，保留配色、字体、边框及布局。
  • 保留原 HTML/SVG/Chart.js 表达。渐变在主动改色前不变；自定义纯色只覆盖选中的数据项。曲线用点或对应线段颜色，面积图按采样区间着色。
  • 重复 HTML 分类及 Chart.js 仍可增删数据；新增的复杂 SVG 曲线／面积／环形及像素图绑定保留已有采样数量，不推断任意新图形结构。
  • 普通表格、独立指标卡与业务说明不增加计数动效、不猜测跨图公式。既有工程不会自动替换为新版模板；原下载模板文件夹保持不改写。
  • 导出的离线字体完整性沿用原字体缓存规则；测试允许尚未缓存字体保留在线引用。Windows 未做实机验证。此轮通过不代表任意第三方 HTML 都能自动原样编辑。
