内部操作接口 v1

适用于编辑器 v0.3.17 / v0.4.0。第一阶段提供“读取页面与图表 → 修改数据 → 预览 → 保存副本”的操作链。现有按钮和工作流程继续可用。

这是编辑器页面内部的 JavaScript 接口。v0.4.0 已提供配套本地 MCP 连接器，见 连接使用指南。普通用户可通过原有界面或已配置的 Agent 编辑；开发者也可在编辑器主页面的控制台或同页集成代码中调用。

入口与约定

const api = window.htmlStudioAPI;
api.version;       // '1.0'，接口版本，与编辑器版本区分
api.getState();    // 当前文档、修订号、页面、预览及忙碌状态
api.describe();    // 16 个命令的参数定义
await api.execute({ command: 'pages.list' });

先通过原界面导入 HTML 或工程。请求及返回值都是可序列化的数据，不返回 DOM 对象，也不接受任意 JavaScript。入口对象只读。参数不符合定义、包含未知字段或命令时会返回错误。

// 成功
{ ok: true, apiVersion: '1.0', context: { token, ... }, result: ... }
// 失败；execute 正常返回错误对象，调用者需要检查 ok
{ ok: false, apiVersion: '1.0', context: { token, ... },
  error: { code: 'STALE_DOCUMENT', message: '...', details: ... } }

标注为“写”的命令必须传入上一次响应的 context.token，格式为 {documentId, revision}，以避免将旧操作应用到新文档。页面切换、预览及文件生成也采用此约定。重新导入、撤回或重做导致文档重建后，应重新读取目标及 token，不能沿用缓存的 DOM 或旧请求。元素 ID 来自编辑器的 data-hs-id，不以可变的页码和标题作为唯一定位依据。

命令清单

命令类型主要用途
document.read读工程名称、状态及当前上下文；空工作台也可读取。
pages.list读页面 ID、序号、标题及当前页标记。
pages.select写按 pageId 切换页面；先退出预览。
elements.list读按 pageId、offset、limit 分页读取图层摘要，默认 100，最多 500 条。
charts.list读指定页面的图表候选及表格。候选不等于可编辑，应再 charts.read 检测。
charts.read读当前页目标的数据、绑定状态、能力及只读单元格；未绑定时返回 detectionId。
charts.bind写传入 id、acceptDetected: true、detectionId，确认识别结果并保留原样绑定。
charts.update写传入 id 和 cells，整批验证后修改单张图表或表格；一批对应一次撤回。
charts.structure写按 axis: row/column、operation: add/delete/rename、index 操作分类或系列；可传 name。add 在指定索引后插入。
history.undo / history.redo写共用编辑器历史；操作后使用新上下文。
preview.start写预览当前页并等待实际可见内容就绪；默认 15 秒，timeoutMs 上限 20 秒。
preview.status读预览是否开启及当前加载状态。
preview.stop写退出预览，返回编辑状态。
files.create写生成 project / html 内容、文件名及 MIME 类型，供调用者处理。
files.download写通过浏览器下载副本，返回文件名及字节数；不覆盖原文件、不修改当前工程名。

图表数据与范围

图表行列索引从 0 开始，数值矩阵不包含分类名和系列名。表格则按整个网格索引，包含标题行与标题列。charts.update 格式为 cells: [{row: 0, column: 0, value: 1200}]。图表接受有限数值，表格还接受文本及既有引擎支持的公式，例如 =SUM(B2:B4)。表格读取结果中的 raw 保留原始文本/公式，values 为计算结果。

渲染方式本版接口范围
SVG可识别的普通、分组、水平、堆叠柱状图，以及瀑布图、气泡图。气泡的 X/Y/面积为固定三列，瀑布图为固定数值列；自动合计不能直接修改。
HTML/CSS可识别的单系列柱子、占比条；支持增删分类，数值列固定。
Chart.js 3/4bar、line、radar、pie、doughnut、polarArea，通过隔离副本读取和计算，再应用结果。
编辑器内置图表柱状、折线、饼图；已绑定表格的图表应修改源表格。
HTML 表格支持单元格、基础公式、已识别合计及热力配色联动。API 暂不开放表格行列结构操作，原界面的行列功能仍可使用。

以 charts.read 返回的 capabilities、readonly、limits 和后续校验结果为准。接口复用现有识别规则，不能把任意图片、未知 Canvas 或任意网页脚本自动转换成可编辑图表；不支持的目标明确返回错误。未绑定的图表先读取，再由调用者核对目标、数值和识别结果，最后显式绑定。

detectionId 有效期为 5 分钟，与具体目标、文档修订和识别数据关联，最多缓存 64 项。若脚本在读取与绑定之间生成不同数据，会返回 DETECTION_CHANGED，要求重新读取核对。接口不会自动接受变化后的数据。

完整调用示例

以下在编辑器主页面执行。先读取并核对页面和图表，再运行修改步骤；示例会把所选图表第一行第一列改成 1200。

const api = window.htmlStudioAPI;
const check = r => {
  if (!r.ok) throw Error(r.error.code + ': ' + r.error.message);
  return r;
};
const pages = check(await api.execute({command: 'pages.list'}));
console.table(pages.result); // 根据返回列表选择目标页
const targetPage = pages.result.find(p => p.active) || pages.result[0];
check(await api.execute({
  command: 'pages.select', params: {pageId: targetPage.id},
  expected: pages.context.token
}));
const list = check(await api.execute({command: 'charts.list'}));
console.table(list.result); // 核对后将目标 ID 填入下一行
const chartId = '替换为目标图表 ID';
let read = check(await api.execute({
  command: 'charts.read', params: {id: chartId}
}));
console.log(read.result); // 核对数据及能力，确认后再执行下面的写操作

if (!read.result.bound) {
  read = check(await api.execute({
    command: 'charts.bind',
    params: {id: chartId, acceptDetected: true,
             detectionId: read.result.detectionId},
    expected: read.context.token
  }));
}
const edited = check(await api.execute({
  command: 'charts.update',
  params: {id: chartId, cells: [{row: 0, column: 0, value: 1200}]},
  expected: read.context.token
}));
const preview = check(await api.execute({
  command: 'preview.start', expected: edited.context.token
}));
// 检查预览；之后退出并下载副本
const stopped = check(await api.execute({
  command: 'preview.stop', expected: preview.context.token
}));
check(await api.execute({
  command: 'files.download',
  params: {format: 'project', name: '报告-修改副本'},
  expected: stopped.context.token
}));

错误恢复与保存

  • BUSY：另一个接口请求未完成，请串行调用。
  • UI_BUSY：用户正在输入、拖动或使用弹窗，完成操作后重试。异步期间发生这类变化也会阻止回写。
  • STALE_DOCUMENT：文档或编辑状态已改变。重新读取、重新核对操作，不要仅换 token 后盲目重放。
  • EXPECTED_REQUIRED / INVALID_ARGUMENT：缺少版本令牌或参数不合法，请按 describe() 修正。
  • BINDING_REQUIRED / DETECTION_REQUIRED / DETECTION_CHANGED：重新读取并确认识别结果，再绑定。
  • PAGE_NOT_ACTIVE / PREVIEW_ACTIVE：切换目标页或退出预览后再编辑图表。
  • LOCKED / READ_ONLY_CELL / LINKED_DATA：检查锁定、自动合计和绑定的数据源；不要绕过保护。
  • UNSUPPORTED / LIMIT_EXCEEDED：该结构或数量暂不支持；保留原图，接口不会自动换样式。
  • PREVIEW_NOT_READY：等待超时不等于可见内容已就绪；可继续读取 preview.status 或主动退出。
  • MISSING_FONTS：默认保存不弹窗，返回缺失字体信息。补齐字体后重试，或明确传入 missingFonts: 'online' 允许在线字体回退，此时副本不保证完全离线。原界面保存仍保留原有提示。

files.create 返回文件内容，不代表已写入磁盘；files.download 触发浏览器下载，实际落盘位置由浏览器决定。一次 charts.update 仅处理一张图表，整批先校验并共用撤回历史；本版没有跨多张图表的原子事务。

后续可扩展边界

本版未开放通用文字/样式写接口、页面复制删除排序接口、任意矢量编辑或自动导入接口。后续可在同一命令层逐步增加。v0.4.0 的连接器负责 MCP 传输、当前工程授权和会话管理。页面对象自身并不是网络服务。宿主可在 execute(request, {signal}) 中传入 AbortSignal，在异步图表写入前取消操作；已完成的同步步骤不会自动回滚。
