通用编辑 MCP · v0.5.0

本地版本 · 2026/11/3 · Chrome 156.0.8078.80 · 126 项检查通过

新增 14 个通用编辑工具，MCP 总计 31 个。此报告记录本轮变更相关回归，不代表所有任意 HTML、全部外部动效和所有 Agent 客户端都已覆盖。

本次交付

  • 查找/选中图层、读取计算样式与文字片段；批量修改普通文本和富文本片段，保留原标签。
  • 字体、字号、颜色、行高、字距、对齐、字形；填色/渐变、描边、圆角、阴影、透明度、旋转。
  • 位置尺寸、对齐分布、Flex/Grid 排列、方向、换行、间距与内边距；自由布局转换须明确确认。
  • 新建文字/容器/基础 SVG 形状，复制删除、重命名、显隐锁定、前后顺序和组合解绑。
  • 所有通用写操作继续经过工程授权、修订校验和 operationId 去重；单次写入为一个撤回步骤，异常恢复 DOM、选择、历史和修订。一次自然语言请求可能拆成多次工具调用。
  • 构建时从浏览器命令定义自动生成 MCP schema，避免双份接口描述不一致。

实际结果与验证方式

  • 新增操作通过标准 MCP SDK → STDIO → 本机连接器 → 浏览器执行；包含非法批次、重复请求、过期修订和注入异常回滚。
  • 真实 26 页动效报告中修改标题与颜色后，继续修改 SVG 图表并预览。该样本两次通用修改的本机观测总耗时 24 ms，仅为一次测试记录，不是性能保证。
  • 验证编辑、预览、HTML 导出、工程副本和重开的文字、样式及 Grid 布局一致；预览截图也已人工查看。
  • 手动界面的组合解绑、二维旋转/缩放、SVG 子层、祖先 CSS、复制间距和现有数据接口回归通过。
  • Mac 两种包已实际启动、重复打开、编辑文字/样式/图表、预览、保存并退出；Intel 通过 Rosetta 运行。Codex 原生加载器已发现 31 项工具，未创建模型对话或修改个人配置。
  • 重复构建应用时发现启动进程被系统结束；改为原子替换可执行文件，避免原位覆盖已签名文件，随后两架构启动与生命周期检查通过。应用仍只有 ad-hoc 完整性签名。
  • 测试使用临时状态目录、独立浏览器和随机端口；保留用户工程、原文件、个人 Agent 配置和正在运行的连接器。

边界

WorkBuddy、千问办公、豆包工作的连接提示词/配置入口已测试，未在这三个客户端逐一执行完整模型任务。Windows 只检查 PE 架构、运行时、文件和压缩包，未做 Windows 实机运行。Mac 未提供 Apple Developer ID 签名或公证。

图表仍受现有识别器能力约束；表格/图表内部数字使用专门数据接口。普通富文本不包含任意脚本/嵌套复杂结构。整页不能当图层删除、移动或组合；MCP 本版只提供页面读取/切换，页面增删排序仍通过手动界面。拆散容器可能失去底色、阴影、裁剪及伪元素，依赖容器的脚本也需在预览中复核。
