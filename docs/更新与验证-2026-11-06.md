# 2026-11-06 更新与验证

本次更新提交根目录的独立 HTML、前端源码、模板适配器和相关回归测试，沿用 v0.5.0 版本号。根目录 HTML 与当前本地版本逐字节一致。

## 功能变化

- 模板库 34 款模板中 30 款包含数据图表，41 个图表、344 个数据元素已增加数据绑定和入场动画。相对数据明确标注，数值和原图几何冲突时按数值校正比例。
- 支持单项自定义颜色、恢复原色；其他项的原渐变不受影响。复杂 SVG 曲线、面积、环形和像素图保持固定数据项数量。
- 预览占满窗口并隐藏编辑区，可切换浏览器全屏；返回后恢复编辑视图。
- 修复 Broadside、Monochrome、Grove、Studio、Signal 中受脚本激活控制的入场标题在编辑态隐藏的问题。原 CSS、脚本、作者设置的透明度和用户手动透明度保持。
