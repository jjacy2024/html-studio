# 开发与测试说明

公开源码的前端、独立 HTML 和连接器与本地最新版一致。测试及构建脚本保留，但私人样本、历史发布包、字体下载缓存和原始 QA 目录不公开。

## 可独立运行的检查

安装 Node.js 24+ 与 Google Chrome 后：

```sh
npm install --ignore-scripts
npm ci --ignore-scripts --prefix connector
npm run check
npm run build:standalone
npm run test:fit-content
npm run test:general-editing
```

浏览器测试使用独立临时上下文。测试输出写入 `qa/`，不进入仓库。连接器测试在随机端口和临时状态目录运行，不修改用户 Agent 配置。

`test:fit-content` 默认执行通用用例；设置 `DECK_FILE` 可增加对应的 26 页回归样本验证。`test:general-editing` 的指定报告用例需 `SALES_FILE`；复制布局和占比条的指定工程用例需 `PREVIEW_PROJECT`。这些用例依赖特定样本结构，不能以任意文件替代。未设置时跳过相应私人样本用例。

仓库中的早期用例、`test:all` 和版本打包脚本是开发历史资料，部分依赖旧默认文档、真实报告、旧发布包或 `qa/` 基准数据，不能视为全新克隆后全部可运行的测试集。公开版本已验证的当前检查见 `公开源码校验.json`。

## 模板素材

`dist/templates.js`、`dist/template-covers.js` 和 `dist/template-font-data.js` 是已生成素材，可直接使用。要从原始模板重新生成，需将上游 beautiful-html-templates 对应的 34 模板版本放在项目同级 `downloads/beautiful-html-templates-34/`。下载字体后可生成字体注册表；字体构建还需 Python fontTools，封面构建需 Playwright 和 Chrome。未在仓库重复保存约 28 MB 的原始字体缓存。

## 打包

当前已验证包见 `releases/`。`node scripts/package-lite-v0.5.0.mjs` 可生成轻量目录，不含 Node.js；第三方许可读取 `licenses/`。正式 `npm run package:lite` 仍要求本地完整 QA 证据、恰好 16 组轻量包回归通过及与受测文件相同的哈希，不绕过发布门禁。

`test:lite` 和报告生成还依赖官方 Node.js 归档基准、最新报告及部分指定样本。这些大型缓存与私人材料不在公开仓库中。无需重新打包即可使用已提供的 ZIP。
